# Learning

Сайт «Пайтон по шагам»: Python с нуля. Схема редактора с подписями (IDLE или VS Code), короткие объяснения и окно, где настоящий Python запускается прямо в браузере (через [Pyodide](https://pyodide.org)).

- `main` — стабильная версия сайта
- `dev` — разработка

## Как открыть локально

```powershell
python -m http.server 5174
```

Потом открыть http://127.0.0.1:5174 в браузере.

Вступление показывается один раз, при первом заходе. Посмотреть его снова: http://127.0.0.1:5174/#/intro

## Ссылки на языке

- `/de`, `/ru`, `/en` — ссылки, которые всегда открывают сайт и показывают предпросмотр на нужном языке.
- Обычная ссылка на сайт: предпросмотр берёт язык телефона, если приложение его сообщает (настроено в `vercel.json`), иначе английский.

## Где что лежит

- `index.html` — каркас страницы
- `css/style.css` — основной дизайн, цвета в начале файла
- `css/motion.css` — вступление, экран подсказок, меню уроков, режим подсказок, анимации
- `js/motion.js` — общие настройки движения (скорости, плавность)
- `js/intro.js` — вступление и экран «А ты знаешь…» про подсказки
- `js/i18n.js` — тексты интерфейса на трёх языках (русский, английский, немецкий)
- `js/lessons.ru.js`, `js/lessons.en.js`, `js/lessons.de.js` — уроки, подписи к схеме и задания. Новый урок добавляется во все три файла с одинаковым `id`
- `js/app.js` — логика: схема, подсветка кода, запуск Python, проверка заданий, прогресс, выбор языка
